# Responsive Image Gallery

A modern and interactive Image Gallery built using **HTML, CSS, and JavaScript**. This project provides a clean and responsive interface for displaying images with category filtering, hover effects, smooth transitions, and a lightbox viewer with navigation controls.

## 📌 Project Overview

The Image Gallery allows users to browse images in an organized grid layout. Images can be viewed in full-screen mode using a lightbox, and users can navigate between images using Next and Previous buttons. Category filters help users display only specific groups of images.

This project demonstrates the use of:

- HTML for structure
- CSS for styling and responsive layouts
- JavaScript for interactivity and image navigation

## ✨ Features

### 🖼 Responsive Image Gallery
- Displays images in a responsive grid layout.
- Automatically adjusts based on screen size.

### 🔍 Lightbox View
- Click any image to view it in an enlarged popup.
- Dark overlay focuses attention on the selected image.

### ⬅➡ Image Navigation
- Previous button to view the previous image.
- Next button to view the next image.
- Circular navigation through all images.

### 🎨 Hover Effects
- Smooth zoom-in effect on image hover.
- Brightness adjustment for better visual feedback.

### ⚡ Smooth Transitions
- CSS transitions create a modern user experience.
- Smooth animations during hover interactions.

### 📂 Category Filters
- Filter images by categories such as:
  - Nature
  - City
  - Animals
- "All" option displays every image.

### 📱 Responsive Design
- Works on:
  - Desktop
  - Laptop
  - Tablet
  - Mobile Devices

## 🚀 How to Run the Project

### Method 1: Directly in Browser

1. Download or clone the repository.
2. Open the project folder.
3. Double-click `index.html`.
4. The gallery will open in your default browser.

### Method 2: Using VS Code

1. Open the project folder in VS Code.
2. Install the **Live Server** extension.
3. Right-click on `index.html`.
4. Select **Open with Live Server**.

## 📖 Usage

### Viewing Images

- Browse images displayed in the gallery grid.
- Click on any image to open it in the lightbox.

### Lightbox Controls

- Click **Next (>)** to move to the next image.
- Click **Previous (<)** to move to the previous image.
- Click **×** to close the lightbox.

### Filtering Images

- Click **Nature** to view only nature images.
- Click **City** to view only city images.
- Click **Animals** to view only animal images.
- Click **All** to display all images.
